# Morph.Protocol

Открытая спецификация протокола для платформы обмена сообщениями Morph.

Morph Protocol определяет данные, состояние и поведение системы, но не определяет способ их отображения пользователю.

**Язык:** [English](README.md) · Русский

## Спецификация

Каноническая спецификация поддерживается на русском языке в каталоге [`spec/ru/`](spec/ru/).

Официальный английский перевод находится в [`spec/en/`](spec/en/). В случае расхождений между английским переводом и русской спецификацией приоритет имеет русская версия.

Текущая экспериментальная ветка протокола: **Morph Protocol v0.1**.

Начать можно отсюда:

- [Обзор](spec/ru/00-overview.md)
- [Терминология](spec/ru/01-terminology.md)
- [Транспорт](spec/ru/02-transport.md)
- [Состояние соединения](spec/ru/03-connection.md)
- [Базовые пакеты](spec/ru/04-packets.md)

Все версии `0.x` являются экспериментальными и могут содержать несовместимые изменения. Версия `1.0` станет первой стабильной спецификацией протокола.
