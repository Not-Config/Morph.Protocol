# Morph Protocol v0.1 — Терминология

> Этот документ является частью канонической русскоязычной спецификации Morph Protocol. При расхождениях с переводами приоритет имеет версия из `spec/ru/`.

Этот документ определяет основные термины, используемые в спецификации Morph Protocol.

## Клиент

Приложение, которое подключается к серверу Morph и реализует Morph Protocol. Клиентом может быть официальное приложение Morph или сторонняя реализация.

## Сервер

Система, принимающая соединения Morph Protocol и поддерживающая авторитетное состояние приложения.

## Соединение

Одно WebSocket-соединение между клиентом и сервером.

## Сессия

Логическая аутентифицированная связь между экземпляром клиента и сервером. При наличии механизма восстановления сессия может существовать дольше отдельного сетевого соединения.

## Устройство

Зарегистрированная установка клиента, связанная с аккаунтом Morph. Криптографическая идентичность устройства не определяется в v0.1, но протокол проектируется так, чтобы её можно было добавить позже.

## Пакет

Одно сообщение Morph Protocol, передаваемое через нижележащий транспорт.

## Команда

Запрос клиента на выполнение операции, которая может изменить авторитетное состояние сервера.

## Результат

Ответ сервера, соответствующий команде. Он сообщает, была ли команда принята, отклонена или завершилась ошибкой.

## Событие

Авторитетное уведомление об изменении состояния. События упорядочиваются идентификаторами последовательности в пределах области синхронизации, определяемой сервером.

## Последовательность

Монотонно возрастающий идентификатор, связанный с упорядоченными событиями. Клиенты используют значения последовательности для обнаружения пропущенных событий и восстановления синхронизации.

## Request ID

Идентификатор, создаваемый клиентом для сопоставления `COMMAND` с соответствующим `RESULT`.

## Capability

Именованная необязательная возможность, поддерживаемая клиентом или сервером. Согласование возможностей позволяет обеспечивать совместимое поведение без предположения, что каждая реализация поддерживает все функции.

## Представление

Визуальное или интерактивное отображение состояния протокола. Представление явно находится вне области ответственности Morph Protocol.
